projects), third-party API integration by docs (REST/cURL/webhooks/postbacks), PageSpeed
optimization, Schema.org, search-indexing basics, fullstack (JS frameworks, Node.js). Stages:
portfolio review → short practical test (markup a block/page to a design, under 1h) → interview
with a live demo of the AI workflow.
