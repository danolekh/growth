## Raw post (abridged)
Frontend Engineer for a mature European e-commerce marketplace (sustainable fashion / green
lifestyle). Customer-facing marketplace features in Next.js, React, TypeScript, with a strong
focus on performance, accessibility, reusable UI components and UX quality. Close collaboration
with backend, UI/UX, product and design-system teams; integration with search, payments,
localization and GraphQL APIs. Must: several years professional React; strong TypeScript/modern
JS; Next.js or comparable SSR/SSG; GraphQL and/or REST API integration; automated frontend testing
(Jest, Testing Library); strong grasp of performance, Core Web Vitals, accessibility (WCAG);
pragmatic technical judgment; experience using AI-powered dev tools for coding/review/testing.
Nice: design systems/component libraries/Storybook, Algolia search, Stripe, i18n/i18next, modern
Yarn/monorepo tooling, ESLint/Prettier/Knip. Responsibilities: build marketplace features,
integrate GraphQL APIs, build reusable UI components with the design-system team, improve
performance/SSR/CDN caching/accessibility, write automated tests, code review, collaborate with
backend/UI-UX/product, use AI tools day to day.
