## Raw post (abridged)
Own features end to end on a mature product with real scale, in a small team, what you ship
reaches production the same week. Work: user-facing features in Node.js/Express and React with
TypeScript, from spec to production; own the full slice (API design, DB schema changes, rollout,

**Must:** 5+ years shipping production software as a full-stack engineer; strong Node.js/Express
(or NestJS) and React, both TypeScript; PostgreSQL (schema, migrations, query optimisation);

hands-on agentic AI tooling (Claude Code, Cursor, Copilot or similar) with the judgment to tell
good generated code from plausible-looking code; comfortable owning a feature alone, DB to UI;
English B2+.

**Nice:** Angular (parts of the platform); MCP servers, custom agent skills or other AI-dev
tooling built by you; React Native; scheduling/logistics domain experience.
