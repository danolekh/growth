Hi!

Your post describes the handoff I specialize in: an AI-generated frontend that's 30-40% there and
needs a real backend and real interactivity to become a product. I work with AI coding tools every
day, so I know what Lovable output looks like and where it usually needs refactoring before
backend logic can attach cleanly.

The closest thing I've shipped is live at https://qrorder.danolekh.com - customers place orders
and staff watch them move across a live board (new, preparing, ready) with realtime updates. That
"create something and watch the process happen" experience is very close to the task-driven flow
you want, and it runs on Next.js + Supabase (Postgres, Realtime, serverless functions) + Stripe
webhooks, the same serverless shape I'd propose for your backend. For the AI-powered side,
https://docqa.danolekh.com is a document Q&A product I built on the Claude API.

I finished my last Upwork contract last week with a 5.0 review; the client wrote that I "kept
finding and fixing problems I didn't even know we had" and always came "with the solution already

so I keep this low-risk for you: we start with a small first slice, an audit of the Lovable
codebase plus a concrete backend plan, and you judge the work before committing to more.

On your three points: for the backend I'd stand up serverless functions with a Postgres database
(Supabase fits well here) behind a clean API boundary, with auth included. For the task-driven
interactivity I'd build a task queue with live status streaming over Supabase Realtime, so users
create a task and watch each step complete in the UI, the way Polsia shows the process. And with
the Lovable code, I'd keep what already works and refactor only the parts that block progress.

One question: when you say "like Polsia", is it mainly the live task feed showing each step, or
also the chat-driven creation flow? If you can share a link or short recording of the MVP, I'll
come back with a concrete plan for the first two weeks.

I'm available now for up to 30 hrs/week and can start today. My rate is $30/hr.

Daniil
